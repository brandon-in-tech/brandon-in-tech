## About Me

I'm an IT Infrastructure Technician based in Las Vegas, Nevada, with professional experience supporting enterprise servers, networking equipment, endpoint management, and Microsoft infrastructure.

Currently, I work on an enterprise infrastructure team at **Executive Personal Computers**, where I service and troubleshoot Dell PowerEdge and HPE ProLiant servers, Cisco switches and routers, enterprise firewalls, and related infrastructure hardware. My work includes hardware diagnostics, firmware management, operating system restoration, network configuration, and secure data sanitization.

My background also includes systems administration and enterprise IT support, with hands-on experience managing **Microsoft Intune, Active Directory, Entra ID, and Microsoft 365** environments.

Beyond infrastructure, I bring a foundation in software development and automation. I've developed and deployed full-stack applications, worked with REST APIs, and built solutions using PowerShell and modern web technologies.

I enjoy understanding technology at every layer—from the physical hardware and operating system to the networks, applications, and services running above them.
