## About Me

I'm an **IT Professional based in Las Vegas, Nevada**, with hands-on experience servicing enterprise servers, network infrastructure, firewalls, enterprise printers, and Microsoft-managed environments. My technical background spans enterprise hardware engineering, systems administration, network troubleshooting, infrastructure restoration, endpoint management, automation, and software development.

I work on a four-person enterprise infrastructure team at **Executive Personal Computers**, supporting **Dell PowerEdge and HPE ProLiant servers, Cisco Catalyst and Nexus switches, ISR routers, and enterprise security appliances**. My work includes advanced hardware diagnostics, firmware and operating-system recovery, RAID and storage management, BIOS/UEFI configuration, iDRAC/iLO administration, network configuration, and secure data sanitization. I regularly work with **Cisco IOS, IOS XE, NX-OS, ROMMON, and bootloader environments**, performing firmware restoration through USB/TFTP, troubleshooting boot failures, configuring interfaces and VLANs, and conducting structured post-service infrastructure validation.

My background also includes enterprise IT support and systems administration with **Microsoft Intune, Active Directory, Entra ID, and Microsoft 365**. Previously serving as the sole on-site IT administrator for a **50+ user, 130+ device environment**, I managed enterprise endpoints, identity and access administration, application deployments, device security policies, Windows migrations, and operational troubleshooting. My experience also includes Microsoft Autopilot, BitLocker encryption, workstation provisioning, and large-scale enterprise hardware deployment.

Alongside infrastructure, I develop **PowerShell automation, Microsoft Graph integrations, REST APIs, and full-stack applications** using modern JavaScript technologies. My software development background includes React, Next.js, Node.js, API integrations, Git/GitHub workflows, and production application deployments. I apply these development skills to infrastructure automation, administrative tooling, technical troubleshooting, and operational efficiency.

I also have extensive experience creating **professional technical documentation**, including standard operating procedures (SOPs), infrastructure implementation guides, troubleshooting runbooks, network topology diagrams, technical PDF reports, PowerPoint presentations, and structured validation documentation. I emphasize clear technical procedures, accurate implementation records, reproducible workflows, and professional reporting standards.

My focus is the full technology stack—from physical hardware and operating systems to networking, cloud services, and the applications they support. I aim to combine **hands-on infrastructure engineering, systems administration, automation, and technical documentation** to build reliable, secure, and maintainable IT environments.
